# 대화형 제작실

라이브러리에서 1–8개 클립아트를 트레이에 담고 **대화로 그림 만들기**를 누른다. 오른쪽에서 **원본 조합** 또는 **AI 이미지**를 선택하고 요청을 입력한다. 오른쪽 위 **제작실**은 저장한 프로젝트를 다시 연다.

- **원본 조합**: Codex가 선택 자산의 실제 미리보기를 확인하고 장면 JSON을 반환한다. 앱은 파일 ID, 체크섬, 좌표, 텍스트, 연결선을 검증한 뒤 원본 SVG/PNG를 렌더링한다. 모델이 반환한 코드나 SVG는 실행하지 않는다.
- **AI 이미지**: Codex의 내장 ImageGen에 선택 자산과 현재 도해를 전달한다. 생성 결과는 PNG로 프로젝트에 복사하며, AI가 다시 그린 그림임을 표시한다. 원본과 동일한 구조나 과학적 정확성을 보장하지 않는다.
- **수정**: 대화로 후속 요청을 보내거나 캔버스 요소를 끌어 이동한다. 요소 선택 후 라벨·좌표·크기를 변경할 수 있다. 텍스트와 화살표는 별도로 추가/수정/삭제할 수 있다. AI 결과 내부 픽셀은 ImageGen 후속 요청으로 수정한다.
- **버전**: 결과 버전 메뉴에서 완료된 원본 조합과 AI 결과를 선택한다. 선택한 버전과 최신 수동 편집이 다음 요청의 참고 자료가 된다.
- **내보내기**: SVG, PNG, 장면 JSON, 대화·작업 이력이 있는 project.json, 출처 목록과 manifest를 ZIP으로 저장한다. AI 결과에는 원본 해상도의 generated.png도 포함한다. SVG의 AI 배경은 래스터이며 텍스트/화살표만 개별 편집 가능하다.

## Codex 연결

공식 Codex CLI가 필요하다. 이 앱은 사용자가 설치한 CLI를 로컬 stdio App Server로 실행한다. CLI를 앱 안에 재배포하지 않는다. `BIOART_CODEX_BIN` 또는 PATH, `~/.local/bin/codex`, Homebrew 설치 위치, Codex 앱의 번들 실행 파일을 순서대로 찾는다. GUI의 축소된 PATH도 지원한다.

기존 ChatGPT 로그인이 있으면 사용한다. 없으면 제작실의 **ChatGPT 로그인**을 누르고 공식 로그인 페이지에서 완료한다. 계정 토큰은 공식 Codex가 관리하며 BioArt 프로젝트에 복사하지 않는다. API 키 방식은 제작에 사용하지 않으며, 구독 제한이나 오류가 발생해도 별도 API 과금으로 자동 전환하지 않는다. 로그인하면 다른 Codex 클라이언트와 로그인 상태를 공유할 수 있다.

이미지 생성은 Codex 사용량을 소모하며 일반 요청보다 한도를 더 빨리 소모할 수 있다. 사용 가능 여부는 설치된 Codex 버전과 계정에 따른다. 검증 버전: codex-cli 0.154.0.

참고: https://learn.chatgpt.com/docs/app-server · https://learn.chatgpt.com/docs/image-generation · https://learn.chatgpt.com/docs/auth

## 저장·실행 경계

`projects/studio-<id>/project.json`에 대화와 작업 상태를 저장한다. 참고 이미지와 생성 PNG도 같은 프로젝트 폴더에 둔다. 편집용 장면은 기존 `projects/scene-<id>.json` 형식을 확장했다. 원본 자료 폴더에는 쓰지 않는다.

동일 작업 폴더에서는 한 번에 한 작업만 실행한다. 프로세스 간 파일 잠금으로 여러 앱 창의 중복 생성과 잘못된 복구를 방지한다. 취소 또는 실패 시 이전 결과를 유지한다. 앱 종료 후 미완료 작업은 재실행 안내와 함께 표시하며 자동으로 추가 생성을 요청하지 않는다. Codex 작업은 최대 10분을 기다린다.

작업은 읽기 전용 샌드박스, 승인 거부, 셸/플러그인/외부 MCP 비활성화 상태에서 실행한다. 원본 조합 결과는 Pydantic으로 검증한다. 이미지 결과는 프로토콜의 이미지 바이트만 디코딩하며 모델이 말한 임의 파일 경로를 읽지 않는다. BioArt 요청은 기존 로컬 호스트·세션 토큰·동일 출처 경계를 사용한다.

## 남은 범위

자동으로 전체 라이브러리에서 재료를 고르는 에이전트, SVG 내부 경로 편집, 이미지 부분 마스크 편집, 일반 드로잉 도구, 다중 사용자 협업은 포함하지 않는다. 기본 입력은 사용자가 선택한 클립아트다. 생성된 도해는 사용자가 내용과 표시를 확인해야 한다.
