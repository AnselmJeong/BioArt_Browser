# 휴대용 프로젝트 ZIP

편집기 상단 **프로젝트 ZIP**에서 현재 저장본을 내보내거나 ZIP을 가져온다. 기존 **내보내기**의 PDF·TIFF 출력 묶음과 구분되는 `bioart-project` v1 형식이다.

## 포함 내용

- `document.json`: 레이어·변환·연결선·마스크·생성기 매개변수와 현재 경로, LaTeX 원문, 표 데이터, 패널과 확대 삽화 참조.
- `assets/`: 도해와 파생 경로가 참조하는 BioArt 원본 SVG/PNG. 파일 ID·체크섬·출처·저작자·라이선스는 manifest에 기록한다.
- `images/`: 도해가 참조하는 생성 이미지. 원래 작업 폴더의 절대 경로를 사용하지 않는다.
- `preview.png`, `SOURCES.md`, `publication.json`, `README.txt`, `manifest.json`.

글꼴 바이너리는 포함하지 않는다. 필요한 글꼴 이름을 기록하며 다른 컴퓨터에서는 미리보기와 비교하고 출판 프리플라이트를 실행한다. 글꼴이 없으면 편집 텍스트의 외형은 달라질 수 있다.

## 새 작업 폴더에서 사용

1. 원래 도해에서 **프로젝트 ZIP → 휴대용 ZIP 만들기**를 누른다.
2. 앱의 **파일 → 작업 폴더 선택…**에서 다른 폴더를 선택한다. 빈 폴더도 지원한다.
3. **도해 편집기 → 프로젝트 ZIP → 프로젝트 ZIP 선택**으로 ZIP을 고른다.
4. **새 사본으로 가져오기**를 누른다. 자료를 새 폴더 안에 보관하고 새 문서 ID, revision 1로 연다.
5. 수정·저장 후 다시 열거나 출판 내보내기를 실행한다. 가져온 도해를 다시 휴대용 ZIP으로 내보낼 수도 있다.

자료는 `projects/imports/<고유 ID>/`에 보관한다. 원본 라이브러리와 다른 프로젝트의 자료를 덮어쓰지 않는다. 같은 ZIP을 여러 번 가져오면 서로 독립적인 사본이 생긴다. 가져온 자료는 프로젝트 전용이며 전체 라이브러리 검색 항목으로 추가하지 않는다.

## 검사와 제한

ZIP 최대 100 MB, 압축 해제 합계 256 MB, 개별 파일 32 MB, 편집 문서 16 MB. 최대 2,049 ZIP 항목을 허용한다. 파일 경로·중복·심볼릭 링크·암호화·압축 방식·CRC·체크섬·자료 참조·문서 스키마를 확인한다. 미래 버전과 출력용 ZIP은 설명과 함께 거부한다. 모든 검증 후 자료를 배치하고 마지막에 문서를 원자적으로 저장하며 실패 시 신규 자료를 정리한다.

내보내기는 현재 카탈로그가 Public Domain 또는 CC-BY로 표시한 자료만 포함한다. CC-BY는 확인된 저작자와 원본 URL이 없으면 중단한다. 생성/사용자 이미지의 재배포 권한은 사용자가 확인한다. 가져온 출처 정보는 ZIP 제공 정보를 보존한 것이며 온라인으로 재검증했다는 뜻이 아니다. 체크섬은 손상 검출 수단이며 발신자 신원을 인증하는 서명은 아니다.
