# 자유 도해 편집기 — 0–4단계

라이브러리 상단 **도해 편집기**에서 시작한다. 빈 문서도 즉시 만들 수 있고, 트레이의 **자유 편집**으로 선택한 자료를 가져올 수 있다. 기존 AI 도해 스튜디오는 별도로 유지된다.

## 기본 작업

- 왼쪽 자료 검색에서 클릭하거나 캔버스에 끌어 넣는다. 기본값은 해당 자료의 SVG이며 PNG도 선택할 수 있다.
- Shift+클릭 또는 범위 드래그로 여러 요소를 선택한다. 핸들로 크기/회전을 조절하고 속성창에서 위치·크기·각도를 수치로 입력한다.
- ⌘C/⌘V, ⌘D, Delete, ⌘Z/⇧⌘Z를 사용한다. 그룹/해제, 정렬/동일 간격, 레이어 순서·숨김·잠금을 지원한다.
- 휠은 확대/축소, 이동 도구와 Space는 작업 영역 이동이다. 격자와 스냅을 각각 끌 수 있다.
- 사각형(모서리 반경 포함), 타원, 다각형, 별, 괄호, 호, 선, 펜, 자유곡선, 텍스트를 그린다.
- 펜은 클릭으로 점을 놓고 Enter로 완성한다. Shift+Enter는 닫힌 경로, Esc는 취소다. 경로 점 편집 도구로 앵커와 곡선 핸들을 조절하고, 점 추가/삭제·직선/곡선 전환·단순화를 적용한다.
- 두 도형/경로를 선택해 합치기·빼기·교집합·제외·분할을 적용한다. 분할 결과는 하나의 복합 경로다. 클리핑 마스크는 앞 도형을 마스크로 사용하고 마스크 해제로 되돌린다.
- 연결선 도구로 한 그림의 가장자리에서 다른 그림까지 끈다. 직선·곡선·직각 경로, 시작/끝 화살표·억제선, 점선·굵기를 설정한다. 대상 이동/회전/그룹 이동을 따라간다. 대상을 지우면 해당 끝점이 자유 끝점으로 남는다.
- SVG 원본에서 **SVG 편집용 복사본**을 누르고 그룹을 해제하면 개별 경로를 편집할 수 있다. 원본은 변경하지 않는다.

## 저장과 출력

변경을 확정하면 로컬 백엔드에 자동 저장한다. **모든 변경 사항 저장됨**은 서버가 원자적 저장을 완료한 뒤 표시한다. 같은 문서를 여러 창에서 수정하면 revision 충돌을 표시하며, 재시도 또는 새 사본 저장을 선택한다. Undo/Redo도 새로운 revision으로 저장한다. 작업 중 Undo 이력은 메모리에 있고 앱 재시작 후에는 초기화된다.

문서는 작업 폴더의 `projects/doc-*.json`에 저장한다. 실패한 저장의 복구본은 내부 디스크 `~/Library/Application Support/BioArt Browser/Recovery/<workspace hash>/`에 보관한다. 다시 열 때 복구본을 새 도해로 열 수 있다. 저장 요청이 서버에 도달하기 전의 강제 종료까지 보장하는 오프라인 저널은 아니다.

**이전 도해 가져오기**는 기존 0.1/0.2 장면을 보존하고 새 문서를 만든다. 원래 프로젝트/대화는 `sourceSceneId`로 추적할 수 있다. 이전 AI 작업의 대화 이력을 새 편집기에서 직접 수정하는 기능은 후속 단계다.

**내보내기**에서 출력 너비(mm)와 DPI를 정하고 프리플라이트를 실행한다. PDF·TIFF·PNG·SVG를 선택할 수 있다. 기본값은 174 mm / 600 DPI이며 높이는 아트보드 비율로 계산한다. 85/174/180 mm 빠른 선택은 특정 저널 규정을 보증하지 않는다.

- **윤곽선**: PDF·SVG의 글자 외형을 고정한다. 텍스트 검색·편집 기능은 사라진다.
- **PDF 글꼴 포함**: 실제 사용 글꼴을 부분 포함하고 검색 가능한 텍스트를 보존한다. SVG는 설치된 글꼴을 참조하므로 별도 경고한다. 원래 경로로 생성된 수식은 검색 텍스트가 아니다.
- **프리플라이트**: 출력 물리 크기에 따른 작은 글씨·가는 선, 원본 이미지의 유효 DPI, 경계 밖 객체, 투명도, 출처·라이선스, 글꼴 대체·누락을 검사한다. 표시할 수 없는 문자와 누락 원본, 과도한 출력 크기는 출력을 차단한다. 경고의 ‘객체 보기’로 해당 요소를 선택할 수 있다.
- **백그라운드 출력**: 창을 닫아 편집을 이어가도 시작 시점의 저장본을 출력한다. 진행률·취소와 결과 버튼을 제공한다. 설정은 도해별로 저장한다. 앱은 출력 완료까지 열어 둔다.
- **품질**: TIFF는 LZW 무손실 압축이며 PNG/TIFF에 DPI와 sRGB ICC를 기록한다. PDF는 벡터를 유지하며 필터 효과만 부분 이미지로 렌더링한다. 원본 래스터의 해상도가 낮으면 출력 DPI를 높여도 개선되지 않는다. 한 번에 한 작업, 5,000만 픽셀/한 변 20,000픽셀 한도를 적용한다.

출력 폴더·ZIP에는 선택한 그림 파일, document.json, manifest.json, SOURCES.md, preflight.json/txt, quality.json이 포함된다. `quality.json`은 실제 파일의 크기·DPI·폰트·ICC·체크섬 검사 결과다. 이 ZIP은 출력 묶음이며 다른 작업 폴더로 가져오는 휴대용 프로젝트 형식은 아니다. PDF/X·PDF/A·CMYK 인증은 지원하지 않는다.

## 휴대용 프로젝트

상단 **프로젝트 ZIP → 휴대용 ZIP 만들기**는 편집 문서와 필요한 원본 자료·생성 이미지·출처·미리보기·출력 설정을 함께 저장한다. **프로젝트 ZIP 선택 → 새 사본으로 가져오기**로 다른 작업 폴더에서 재편집한다. 앱의 **파일 → 작업 폴더 선택…**은 빈 폴더도 지원한다. 가져오기는 기존 도해를 덮어쓰지 않으며 반복해서 가져와도 독립적인 사본이 생긴다.

폰트 파일은 포함하지 않고 필요한 글꼴 이름을 기록한다. ZIP 100 MB / 압축 해제 합계 256 MB 한도와 체크섬·경로·문서 참조 검사를 적용한다. 재배포 조건을 확인할 수 없는 원본 자료는 내보내기를 중단하고 이유를 표시한다. [상세 형식과 사용법](PORTABLE_PROJECTS.md), [설치 앱 검증](PORTABLE_VALIDATION.md).

## 엔진 결정

- Fabric 7.4.0: 선택·변환·텍스트·그룹·경로 제어점과 캔버스 상호작용.
- Paper.js 0.12.18의 core 배포본: 경로 Boolean 연산과 단순화. PaperScript의 동적 평가가 없는 core를 사용해 기존 CSP를 유지한다.
- 문서 v1: 렌더러 객체 JSON과 분리한 노드/중심 기준 변환/스타일/경로/그룹/연결 참조 모델. Python 검증기와 SVG 정본 출력기가 같은 문서를 읽는다.
- 원본 배치와 편집 복사본을 구분한다. 필터·패턴·복잡한 마스크 등 지원하지 않는 효과, 변환 후 외형 차이가 큰 SVG는 복사본 변환을 거부한다. 두 배율의 raster 비교는 손상 방지 장치이며 모든 SVG에 대한 수학적 동등성 증명은 아니다.


## 3단계: 과학 제작

좌측 **과학 제작** 탭에서 10개 생성기(세포막, 소포/리포좀, 세포와 핵, 수용체, 항체, DNA, RNA, 입자 군집, 하이드로젤, 튜브)를 추가합니다. 선택한 객체의 **생성 설정 편집**으로 크기·색·간격·두께 또는 개수·시드를 바꿉니다. 설정은 버전 1 메타데이터와 일반 벡터 geometry로 저장하며, 재열기만으로 재생성하지 않습니다. 생물학 객체는 개념 설명용입니다.

과학 브러시는 막 이중층, 분자 사슬, DNA, RNA, 섬유를 지원합니다. **브러시로 그리기**로 자유곡선을 그리거나, 펜/곡선 경로를 선택한 뒤 **선택 경로에 적용**을 사용합니다. 반복 배치는 곡선 길이를 따라 이루어지고 막은 급한 곡률에서 두께를 줄입니다. 자기 교차 경로의 겹침까지 자동 해결하지는 않습니다. **브러시 기준 경로 꺼내기**로 경로 사본의 점을 수정하고 다시 적용할 수 있습니다.

**개별 도형 편집 사본**은 생성기 원본을 남겨 두고 일반 그룹 사본을 만듭니다. 사본을 그룹 해제하여 구성 도형을 편집합니다. 생성기에서 바로 그룹 해제를 눌러도 원본 보존 사본을 먼저 만듭니다.

**확대 삽화**는 원본 객체의 로컬 좌표 영역을 원/사각형으로 자릅니다. 자동 반영을 켜면 원본 geometry 수정이 반영되고, 끄면 현재 모습이 고정됩니다. 원본 삭제 또는 원본 그룹에 삽화가 포함되는 경우 마지막 모습을 고정해 보존합니다. 삽화를 포함한 객체를 다시 확대하는 순환 구조는 거부합니다. 크롭 중심/범위는 설정창의 0–1 좌표로 편집합니다. 물리 배율이나 축척을 의미하지 않습니다.

**LaTeX 수식**은 MathJax 3.2.2의 base/AMS를 앱 내부에서 렌더링합니다. 외부 패키지·URL·HTML 명령을 로드하지 않습니다. 원문과 벡터 윤곽선을 함께 저장하므로 SVG/PNG 출력 시 수식 폰트 다운로드가 필요 없습니다. 길이 2,000자, 크기 8–160을 지원하며 오류가 있으면 기존 수식을 유지합니다.

**표**는 `|`로 열, 줄바꿈으로 행을 나누어 입력합니다. 최대 20행 × 12열, 셀당 200자입니다. 머리글/색/셀 크기/글자 크기를 다시 편집할 수 있습니다. 긴 내용은 셀에서 잘리므로 셀을 넓히거나 글자를 줄이세요. **패널 템플릿**은 최대 12개 프레임과 자동 라벨, 여백을 만듭니다. 내용과 독립된 배경 프레임이며 필요하면 레이어 잠금을 사용합니다.

시작 템플릿 5개는 기존 문서를 저장하고 **새 도해**로 열립니다. 세포 신호전달, DNA와 전사, 약물 전달, 실험과 결과, 막·분자 브러시가 포함됩니다. 표에 포함된 대시와 농도 값은 편집용 예시이며 실험 결과를 나타내지 않습니다.
