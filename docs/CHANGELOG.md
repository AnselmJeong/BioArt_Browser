# 변경 기록

## 0.4.0 · 2026-10-14

- 자유 도해 편집기: 레이어·그룹·변환·정렬, 벡터 경로 편집, Boolean 연산, 연결선과 클리핑 마스크.
- 과학 제작: 세포막·DNA 등 생성기, 과학 브러시, 확대 삽화, LaTeX 수식, 표와 패널 템플릿.
- 논문 출판: PDF·TIFF·PNG·SVG, 물리 너비·DPI, 폰트 포함/윤곽선, 프리플라이트와 출력 품질 검사.
- 휴대용 프로젝트 ZIP: 편집 문서·참조 자료·출처·미리보기·출력 설정을 포함하여 다른 작업 폴더로 가져오기. 빈 작업 폴더 지원.
- 문서 revision 충돌 감지, 자동 저장·재열기, ZIP 경로·크기·체크섬·참조 검증.

앱 표시, macOS 번들, JavaScript 패키지 및 Python 백엔드 버전을 0.4.0으로 맞췄다. 문서와 휴대용 ZIP의 스키마 버전은 변경하지 않는다. Rust 출력 도구의 독립 패키지 버전도 유지한다.

검증: [출판 출력](PHASE4_VALIDATION.md), [프로젝트 휴대성](PORTABLE_VALIDATION.md). 글꼴 바이너리 동봉, PDF/X·PDF/A·CMYK 인증은 지원하지 않는다.
