## 실제 macOS 앱 검증

검증 대상은 `/Applications/BioArt Browser.app`의 native WKWebView다.

1. 빈 문서에서 검색으로 폐·폐포 SVG를 추가하고 위치/회전을 수정했다. 한글 제목과 독립 텍스트를 입력했다.
2. 두 그림 사이 연결선을 만들고 두 대상의 연결 상태를 확인했다. 그림을 그룹화해 세로 위치 425→500으로 옮긴 후 저장된 연결선의 위치와 대상 ID가 따라오는 것을 확인했다.
3. 둥근 사각형을 직접 그리고 채움 제거·모서리 반경 18을 저장했다.
4. 별도 20개 실제 SVG 자료 문서를 앱에서 열어 전체 선택→이동→Undo를 실행했다. Undo 후 노드 JSON이 이전 상태와 정확히 일치하고 revision은 2→4로 증가했다. 앱의 내보내기 버튼으로 결과 파일을 생성했다.
5. SVG 복사본 변환 성공(Cross Mark)과 외형 차이에 따른 변환 거부(Schematic Protein Shape)를 모두 확인했다. 성공한 복사본을 2개 경로로 분리했다. 열린 Cross Mark 선의 면적 Boolean 결합은 빈 결과로 거부됐고 기존 경로는 유지됐다.
6. 앱을 완전히 종료해 부모/백엔드 프로세스 종료를 확인했다. 새 프로세스와 새 loopback 포트로 다시 실행하고, 도해 편집기에서 마지막 문서를 열었다.
7. 재시작 전후 문서 파일이 바이트 단위로 같았다. 재시작 후 앱 내보내기 버튼을 다시 눌러 만든 SVG·PNG도 재시작 전 결과와 SHA-256이 같았다. ZIP 무결성, 1400×850 PNG, 출처 manifest와 경고 없음도 확인했다.

### 재실행 문제 처리

새 번들 실행 중 외장 볼륨 경로에서 런타임 시작이 정지하는 현상을 관찰했다. 백엔드 cwd를 외장 작업 폴더 대신 실행 파일 디렉터리로 변경하고, `--workspace`로 자료 경로를 전달하도록 수정했다. 설치본에서 기존 작업 폴더를 파일 메뉴로 한 번 다시 선택한 뒤 정상 연결됐다. 마지막 종료/재시작에서는 재선택 없이 약 0.3초에 백엔드 준비가 완료됐다. 외장 볼륨의 dist 번들 직접 실행보다 검증한 `/Applications` 설치본을 사용한다.
